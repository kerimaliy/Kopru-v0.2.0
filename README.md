# YakınKöprü v0.2 Beta
## YakınKöprü v0.2 Beta

YakınKöprü, cihazlar arasında dosya paylaşımı için geliştirilen bir Android uygulamasıdır.

### Bu sürümde
- Yakındaki cihazları bulmaya yönelik bağlantı özellikleri
- Büyük dosya aktarımı için geliştirmeler
- Şifreli dosya aktarımı
- Yenilenmiş, animasyonlu kullanıcı arayüzü

**Not:** Bu bir beta/test sürümüdür. Bazı bağlantı ve aktarım özellikleri henüz farklı cihazlarda kapsamlı olarak test edilmemiştir.

### Kurulum
1. Aşağıdaki APK dosyasını indirin.
2. Android cihazınızda dosyayı açın.
3. Gerekirse bilinmeyen uygulama yükleme iznini verin.
4. Uygulamayı yükleyin.
